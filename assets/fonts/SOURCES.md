# Fontes locais da extensão

Arquivos originais, sem modificações. Licenças SIL OFL 1.1 incluídas junto aos arquivos. As fontes são expostas somente às origens dos players pelo manifesto; os textos de licença são incluídos no pacote sem exposição web.

Somente espaços ao fim das linhas dos textos de licença foram normalizados; texto e arquivos de fonte permanecem intactos.

- OpenDyslexic regular/bold WOFF2: https://github.com/antijingoist/opendyslexic/tree/1824da5c0e41dc3e13ffc7f3a636dcaf695d61b7/compiled
- DM Sans variável TTF: https://github.com/google/fonts/tree/e9678a5385322c63730122ba464765baad83cfd8/ofl/dmsans
- Libre Caslon Text variável TTF: https://github.com/google/fonts/tree/e9678a5385322c63730122ba464765baad83cfd8/ofl/librecaslontext

Não há downloads de fontes ou folhas de estilo externas durante o uso do painel de configurações. OpenDyslexic também é declarada no Shadow DOM das legendas para que a preferência de acessibilidade use a fonte empacotada.
